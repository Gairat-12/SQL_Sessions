Standard Workflow (Sessions 1–6, Session 9)
One issue, one branch, one PR per session

	Step 1 — Create Issue on GitHub:
GitHub → Issues → New issue
Title: Session_X
Description: SQL Query Assignment For Session X
Assign yourself → Submit
Note the issue number

	Step 2 — VS Code Terminal:
git switch main
git pull
git switch -c Session_X
git add "Session_X"
git commit -m "Add Session X SQL practice assignment - closes #XX"
git push -u origin Session_X
Step 3 — GitHub:

Compare & pull request → Assign yourself → Create pull request → Merge pull request → Confirm merge

Key Rules
Issue numbers and PR numbers share the same sequence — always check the actual issue number before writing the commit message
closes #XX in the commit message auto-closes the issue when the PR is merged
Always run git switch main && git pull before creating a new branch
Branch name must match the feature (e.g. Session_7-Stats)
